
# Grab Fare Calculator
Python based Grab Fare Calculator developed as part of the LDCW6123 Fundamentals of Digital Competence for Programmer assignment.

## Project Description

This program allows users to estimate their Grab fare based on several factors:

* Vehicle type
* Travel distance
* Peak hour
* Number of passengers

The program calculates an estimated fare using different base fares and rates for each vehicle type. Additional charges are applied for peak hours and additional passengers.

## Vehicle Types

The program supports three vehicle types:

1. GrabCar
2. GrabCar Plus
3. GrabCar Premium

## Features

* Graphical User Interface (GUI)
* Vehicle type selection
* Distance input
* Peak hour selection
* Passenger selection
* Automatic fare calculation
* Peak hour surcharge calculation
* Additional passenger surcharge
* Input validation
* Estimated fare display

## Technologies Used

* Python
* Tkinter
* Visual Studio Code
* Git & GitHub

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Run the Python GUI file.

Example:

```bash
python gui.py
```

The Grab Fare Calculator window will then open.

## Project Purpose

The purpose of this project is to demonstrate the development of a simple interactive program based on ride-hailing technology. It demonstrates programming concepts such as functions, conditional statements, user input, calculations, validation, and graphical user interface development.
